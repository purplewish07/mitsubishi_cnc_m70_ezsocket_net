## 技術細節

### Y188F/YC67 判斷邏輯

兩個override函數都使用特殊的PLC地址來判斷數值來源：

**Y188F (Spindle Override)**:
- 位置: section 53, subsection 16287 + 96*(system_no-1)
- 類型: T_CHAR
- 判斷:
  - bType == 0: 使用代碼映射方式（Y1888）
  - bType != 0: 使用R參數直接讀取（R7008）

**YC67 (Feed Override)**:
- 位置: section 53, subsection 13175 + 320*(system_no-1)
- 類型: T_CHAR
- 判斷:
  - bType == 0: 使用代碼計算方式（YC60）
  - bType != 0: 使用R參數直接讀取（R2500）

### 代碼映射表 (Y1888)

主軸倍率代碼到百分比的映射：
```python
code_map = {
    0x7: 50,   # 50%
    0x3: 60,   # 60%
    0x2: 70,   # 70%
    0x6: 80,   # 80%
    0x4: 90,   # 90%
    0x0: 100,  # 100% (default)
    0x1: 110,  # 110%
    0x5: 120,  # 120%
}
```

### YC60 計算公式

進給倍率計算：
```python
temp_override = (0x0F - (code & 0x0F)) * 10
```

例如:
- code = 0x00: (15 - 0) * 10 = 150%
- code = 0x05: (15 - 5) * 10 = 100%
- code = 0x0F: (15 - 15) * 10 = 0%

### Feed Speed Type 映射

| Type | Section | SubSection | 說明 |
|------|---------|------------|------|
| FA   | 42      | 1          | Actual (實際速度) |
| FM   | 42      | 2          | Modal (模態速度) |
| FS   | 42      | 3          | Start (起始速度) |
| FE   | 42      | 4          | End (結束速度) |
| FC   | 33      | 1          | Command (指令速度) |
