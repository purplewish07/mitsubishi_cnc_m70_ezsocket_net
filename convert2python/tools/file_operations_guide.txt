## 已實現的功能

### 1. 協議層函數 (m70_giop.py)

✅ **mel_fs_open_file(conn, filename, mode)** 
   - 打開CNC文件系統上的文件
   - mode: 0=只讀, 1=只寫, 2=讀寫
   - 返回: (error_code, file_descriptor)

✅ **mel_fs_read_file(conn, fd, need_read_size)**
   - 從打開的文件讀取數據
   - 返回: (error_code, actual_read_size, file_data)

✅ **mel_fs_close_file(conn, fd)**
   - 關閉文件描述符
   - 返回: error_code

✅ **mel_fs_stat_file(conn, filename)**
   - 獲取文件信息（不需要打開文件）
   - 返回: (error_code, file_stat_dict)
   - file_stat包含: mode, file_size, year, month, day, hour, minute, second

✅ **mel_fs_open_directory(conn, dirpath)**
   - 打開目錄
   - 返回: (error_code, directory_descriptor)

✅ **mel_fs_read_directory(conn, fd)**
   - 讀取目錄項（每次返回一個文件名）
   - 返回: (error_code, directory_name)

✅ **mel_fs_close_directory(conn, fd)**
   - 關閉目錄描述符
   - 返回: error_code

✅ **mel_fs_create_file(conn, filename, mode)** 【新增】
   - 在CNC文件系統上創建新文件
   - mode: 0=只讀, 1=只寫, 2=讀寫
   - 返回: (error_code, file_descriptor)
   - 注意: 新文件必須用此函數創建，不能用open_file

✅ **mel_fs_write_file(conn, fd, file_data, write_size)** 【新增】
   - 寫入數據到已打開的文件
   - 返回: (error_code, actual_written_size)
   - 支持分塊寫入

✅ **mel_fs_remove_file(conn, filename)** 【新增】
   - 從CNC文件系統刪除文件
   - 返回: error_code

### 2. 業務層函數 (m70_ezsocket.py)

✅ **read_file(filepath, max_size=512)**
   - 高層封裝，自動處理 open → read → close
   - 只讀模式，安全
   - 返回: (error_code, file_data)
   - 注意: max_size 建議不超過 1000 bytes（CNC系統限制）

✅ **stat_file(filepath)**
   - 獲取文件狀態信息
   - 不打開文件，完全安全
   - 返回: (error_code, file_info_dict)

✅ **list_directory(dirpath)**
   - 列出目錄所有內容
   - 自動處理 open → read循環 → close
   - 返回: (error_code, list[filenames])

```python
LOCAL_FILE_PATH = "downloaded_O3000.NC"
```

執行: `python download_nc_file.py`

### 方式2: 簡單下載代碼

```python
from m70_ezsocket import M70Connection, M70ErrorCode

conn = M70Connection(ip="192.168.1.206", port=683)
conn.connect()

# 下載文件（max_size建議設為1000，系統限制）
error_code, file_data = conn.read_file("M01:\\PRG\\USER\\PART1.NC", max_size=1000)

if error_code == M70ErrorCode.OK:
    with open("PART1.NC", "wb") as f:
        f.write(file_data)
    print("下載成功")

conn.disconnect()
```


### 方式2: 上傳代碼示例

```python
from m70_ezsocket import M70Connection
from m70_ezsocket.m70_giop import M70GIOP

conn = M70Connection(ip="192.168.1.206", port=683)
conn.connect()

# 讀取本地文件
with open("O3001.NC", "rb") as f:
    file_content = f.read()

remote_path = "M01:\\PRG\\USER\\O3001.NC"

# 創建文件（mode=1 表示寫入）
error_code, fd = M70GIOP.mel_fs_create_file(conn, remote_path, 1)

if error_code == 0:
    # 寫入文件
    error_code, written = M70GIOP.mel_fs_write_file(conn, fd, file_content, len(file_content))
    
    # 關閉文件
    M70GIOP.mel_fs_close_file(conn, fd)
    
    if error_code == 0:
        print(f"上傳成功，寫入 {written} bytes")

conn.disconnect()
```

## 高級下載（大文件分塊讀取）

```python
from m70_ezsocket import M70Connection
from m70_ezsocket.m70_giop import M70GIOP

conn = M70Connection(ip="192.168.1.206", port=683)
conn.connect()

# 打開文件
error_code, fd = M70GIOP.mel_fs_open_file(conn, "M01:\\PRG\\USER\\LARGE.NC", 0)

if error_code == 0:
    file_data = bytearray()
    
    # 分塊讀取（每次最多1000 bytes，CNC系統限制）
    CHUNK_SIZE = 1000
    while True:
        error_code, size, chunk = M70GIOP.mel_fs_read_file(conn, fd, CHUNK_SIZE)
        if error_code != 0 or not chunk:
            break
        file_data.extend(chunk)
        print(f"已讀取: {len(file_data)} bytes")
    
    # 關閉文件
    M70GIOP.mel_fs_close_file(conn, fd)
    
    # 保存
    with open("LARGE.NC", "wb") as f:
        f.write(file_data)

conn.disconnect()
```

## 批量下載目錄

```python
conn = M70Connection(ip="192.168.1.206", port=683)
conn.connect()

# 列出目錄
error_code, files = conn.list_directory("M01:\\PRG\\USER")

# 下載每個文件（注意max_size限制）
for filename in files:
    filepath = f"M01:\\PRG\\USER\\{filename}"
    error_code, data = conn.read_file(filepath, max_size=1000)
    
    if error_code == M70ErrorCode.OK:
        with open(f"./downloaded/{filename}", "wb") as f:
            f.write(data)

conn.disconnect()
```

安全性說明
========================================

✅ 已實現的讀取操作（安全）:
   - mel_fs_open_file (mode=0) - 只讀打開
   - mel_fs_read_file - 讀取數據
   - mel_fs_stat_file - 查詢文件狀態
   - mel_fs_read_directory - 列出目錄
   - mel_fs_close_file/close_directory - 關閉句柄

✅ 已實現的寫入操作:
   - mel_fs_create_file - 創建新文件
   - mel_fs_write_file - 寫入數據
   - mel_fs_remove_file - 刪除文件

⚠️ 寫入操作注意事項:
   - 創建文件時會檢查是否已存在
   - 如果文件已存在，需先刪除再創建
   - 某些程序號可能在CNC系統中被保留（如O3000）
   - 建議使用未使用的程序號（如O3001、O9999）

✅ 資源管理安全:
   - 所有工具程序都有異常處理
   - 自動關閉文件句柄
   - 防止資源洩漏

⚠️ 錯誤碼參考（Mitsubishi專用）:
   - 0x80070002: 文件不存在
   - 0x80070142: 無法打開文件（文件不存在時用write模式打開）
   - 0x80070392: すでに生成されている（文件/程序號已存在）
   - 0x80070393: ファイルを生成できない（無法創建文件）

測試建議
========================================

讀取操作測試順序（最安全）:
1. 先測試 stat_file() - 最安全，只查詢不修改
2. 再測試 list_directory() - 只讀目錄
3. 最後測試 read_file() - 下載文件

寫入操作測試順序:
1. 先測試 stat_file() - 確認目標路徑可用
2. 準備小測試文件（< 100 bytes）
3. 測試 upload_nc_file.py - 上傳文件
4. 使用 download_nc_file.py 驗證上傳結果
5. 測試 delete_nc_file.py - 刪除文件
6. 再次 stat_file() 確認已刪除

完整流程測試:
- 執行 upload_and_delete_file.py
- 完整測試：創建→寫入→驗證→讀取→刪除→驗證刪除

⚠️ 測試注意事項:
- 使用未被佔用的程序號（如O3001、O9999）
- 避免使用系統保留的程序號（如O3000可能被保留）
- 測試前先用stat_file確認文件不存在
- 測試後記得刪除測試文件
