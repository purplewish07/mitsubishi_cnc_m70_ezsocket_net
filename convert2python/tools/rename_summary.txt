## 重命名原因

為了使Python版本的文件結構與C版本更好地對應。

## C版本結構

```
m70_ezsocket.c/h     - 應用層API (業務邏輯)
m70_giop.c/h         - 協議層 (GIOP封裝)
socket.c/h           - 網絡層 (TCP/IP通信)
typedef.h            - 類型定義
```

## Python版本結構 (重命名後)

```
m70_ezsocket.py      - 應用層API (M70Connection類) ✓
m70_giop.py          - 協議層 (M70GIOP類) ✓
m70_socket.py        - 網絡層 (M70Socket類) ✓
typedef.py           - 類型定義 ✓
```

## 重命名詳情

### 文件重命名
- `m70_connection.py` → `m70_ezsocket.py` ✓

### 保持不變
- 類名: `M70Connection` (保持不變)
  * 原因: Python使用面向對象，M70Connection代表連接對象很直觀
  * C版本使用: `m70_conn_t` 結構體 + `m70_cnc_*()` 函數

### 更新的文件
1. `__init__.py` - 更新 import 語句 ✓
2. `test_override_speed.py` - 更新 import 路徑 ✓

### 無需更新的文件
- 其他所有文件通過 `from m70_ezsocket import M70Connection` 導入
- 因為 `__init__.py` 已更新，所有外部引用自動生效 ✓
